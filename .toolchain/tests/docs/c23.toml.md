# .toolchain/tests/cases/c23.toml

The group `c23` checks `.toolchain/tools/c23.py`.
Each case writes the source `{case}/p/src/a.c` and `{case}/p/project.toml`, and runs `c23.py --root {case}/p`.
The source of a case has one older spelling. The source of its false variant has the newer spelling.
In this document, each path of the small project starts with `{case}/p`.

| Case | Older spelling in the source | Newer spelling in the false variant |
| --- | --- | --- |
| NULL | `p = NULL;` | `p = nullptr;` |
| stdbool.h | `#include <stdbool.h>` | `#include <stdint.h>` |
| _Bool | `_Bool b;` | `bool b;` |
| _Alignof | `n = _Alignof(int);` | `n = alignof(int);` |
| _Alignas | `_Alignas(8) int n;` | `alignas(8) int n;` |
| _Static_assert | `_Static_assert(1, "one");` | `static_assert(1);` |
| _Thread_local | `_Thread_local int n;` | `thread_local int n;` |
| _Noreturn | `_Noreturn void stop(void);` | `[[noreturn]] void stop(void);` |
| __attribute__ | `__attribute__((cold)) void stop(void);` | `[[gnu::cold]] void stop(void);` |
| an enum with no name | `enum { ONE };` | `enum kind : int { ONE };` |
| an enum with no width | `enum kind { ONE };` | `enum kind : int { ONE };` |
| a parameter that is not used | `(void)n;` | `[[maybe_unused]] int n` |
| an initializer of zeros | `int a[2] = {0};` | `int a[2] = {};` |
| a macro for a number | `#define SIZE 4` | `constexpr int SIZE = 4;` |

In each case, `c23.py` writes `src/a.c:1:`, the older spelling, `->` and the newer spelling. Then it stops.
Each claim names the older spelling that the case holds.

| Case | Claim | False variant |
| --- | --- | --- |
| a comment and a string | The source has `NULL` in a comment and in a string only. `c23.py` ends with 0. | The source also has `NULL` out of them. |
