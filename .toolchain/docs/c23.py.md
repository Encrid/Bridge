# .toolchain/tools/c23.py

`c23.py` finds the older spellings of C in the code of the project.
`docs/contributing/coding_style.md`, *C23* gives each older spelling and its newer spelling.
`c23.py` reads the same files as `.toolchain/tools/style.py`. It does not read the comments and the strings.

```sh
python .toolchain/tools/c23.py [--root <folder>]
```

## Output

Each older spelling is a fault: `<path>:<line>: <older>  ->  <newer>`.
Its faults follow the paths, then the older spellings, then the lines.
The output follows `.toolchain/docs/shared.py.md`, *The report of a check*.

## Functions

| Function | Result |
| --- | --- |
| `main()` | Reads the files, and writes each older spelling. |
