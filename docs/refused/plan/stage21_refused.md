# What was refused: Stage 21

What was weighed in `stage21.md` and refused, each with the condition that would bring it back.

## What it is called

Of `stage21.md`, *What it is called*.

Refused: a distribution, made of units. It is two words for one idea, and a unit says nothing
by itself. The condition that brings it back is none.

Refused: a hand-over, which is what it was called while it was asked for. It describes and
does not name, and nobody would look for it. The condition that brings it back is none.

Refused: artifacts, the word of the hosting service. It is said of everything a build makes,
which is the opposite of what is set apart. The condition that brings it back is none.

## What the library's package holds

Of `stage21.md`, *What the library's package holds*.

Refused: the debug symbols, as a package of their own. On Windows they are eight times the
library, each system keeps them differently, and no host has asked. The condition that brings
it back is a host that has to read a failure inside the library.

Refused: `licence.md` and `cla.md` in the package. The first cites documents that are not
there outside the tree, and the second is for who contributes and not for who links. The
condition that brings it back is none.

## What a backend's package holds, and the SDK's

Of `stage21.md`, *What a backend's package holds, and the SDK's*.

Refused: one package for a backend, with its SDK inside. A host that only runs modules would
take headers it never opens, and how a module is written would be answered inside how one is
run. The condition that brings it back is none.

Refused: the SDK's package left until a host asks for it. It is asked for by the next stage
of the host that asked for this one. The condition that brings it back is none.

## The statement a package carries

Of `stage21.md`, *The statement a package carries*.

Refused: JSON. A host in C would need a reader for it to check three hashes, and the name such
a file usually has means something else. The condition that brings it back is a fact to state
that lines cannot hold.

Refused: a file of checksums in the form the common tools check, and the commit only in the
archive's name. What a package is would depend on what it is called. The condition that brings
it back is none.

## Where the packages are published

Of `stage21.md`, *Where the packages are published*.

Refused: files attached to the run that built them. They are gone after ninety days, and with
them the library a host was built against. The condition that brings it back is none.

Refused: one release that always holds the latest `main`. The same address would be a
different library each week, and none could be fetched by its commit. The condition that
brings it back is none.

Refused: a branch that holds the built files. The repository would grow by about 190 MB each
time, for ever. The condition that brings it back is none.

## Which targets are published

Of `stage21.md`, *Which targets are published*.

Refused: only the five targets whose cases passed in the run. A package would then always be
one that ran; and a host on Windows arm64 would have nothing. The condition that brings it
back is a package taken for one that had run, against what its statement says.

## What a run does when a platform fails

Of `stage21.md`, *What a run does when a platform fails*.

Refused: one workflow of five jobs and a sixth that publishes only when all have passed. A
published commit would be whole; and one system failing would keep every host from it. The
condition that brings it back is a host that took a release for whole and found a target
missing.

## The run under load

Of `stage21.md`, *The run under load*.

Refused: ten rounds, as it was. It is nine tenths of 430 counted minutes a run, and seven runs
are a month of them. The condition that brings it back is minutes that are not counted.

Refused: no run under load on the service, and only where the code is written. It would be
true of one platform only, and what it once found was a matter of timing. The condition that
brings it back is none.

## What holds it

Of `stage21.md`, *What holds it*.

Refused: a case on what a package holds, and nothing built from one. Whether what a host is
handed is enough would never be shown. The condition that brings it back is none.

Refused: the program of the tests changed until all of it is built from packages. Its cases
need modules and backends that are the tests' own, which would have to be packaged against
what was ruled. The condition that brings it back is none.
