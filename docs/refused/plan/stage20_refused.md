# What was refused: Stage 20

What was weighed in `stage20.md` and refused, each with the condition that would bring it back.

## What must be open

Of `stage20.md`, *What must be open*.

Refused: a host as an independent work, by an exception of our own, so that anything built on
Bridge may be closed at no cost. It is what the design before this one promised and not what is
wanted now. The condition that brings it back is none.

Refused: the plain General Public License, with no exception. It is this, but for a host that
only runs as a service, which could stay closed and pay nothing. The condition that brings it
back is the Affero licence found to keep away users it was not meant to.

Refused: the exception of `legacy/rust-components` kept for modules and backends, so that a
closed host pays and a closed module does not. It keeps a text of ours, with the question of
seam code compiled into a module to answer, for a distinction that is not wanted. The condition
that brings it back is a host's author who has bought other terms and needs closed modules
from people who have not, if those terms cannot grant it.

Refused: the Lesser General Public License. It lets a closed program link the library at no
cost, which is what is not wanted, and it asks that a user can put a changed library in its
place, which a console or a store does not allow. The condition that brings it back is none.

## Who the holder is

Of `stage20.md`, *Who the holder is*.

Refused: the author's own name in every notice. It names the holder, which is what a notice is
for; and it is a name in 468 files of a repository that is to be public, changed again the day
an entity is formed. The condition that brings it back is a qualified reader finding a working
name too weak.

Refused: an entity formed first, holding the rights by a written transfer. It is the cleanest
to sell from, and it is a cost in law before there is a buyer. The condition that brings it
back is a first buyer.

## The contributor's agreement

Of `stage20.md`, *The contributor's agreement*.

Refused: a transfer of copyright. The holder would own all of it, and it asks the most of a
contributor, in a form that is not valid everywhere. The condition that brings it back is a
buyer who will not take a licence passed on.

Refused: signing by a sentence that the maintainer checks and records by hand, alone or beside
the workflow. The condition that brings it back is a workflow that still cannot run when the
first contribution from outside arrives.

Refused: the signing program `legacy/rust-components` used. It was archived by its authors and
gets no fixes. The condition that brings it back is none.

Refused: no agreement until there is a contributor. The first one would meet a closed door and
a text written in a hurry. The condition that brings it back is none.

## Which versions

Of `stage20.md`, *Which versions*.

Refused: version 3 or any later. A user could then take terms that are not written yet, by an
author who is not the holder. The condition that brings it back is code under a later version
only that Bridge has to be combined with.

## The line in every file

Of `stage20.md`, *The line in every file*.

Refused: the registered identifier, `AGPL-3.0-only`, on a line of its own. A program reads it
and nobody words it wrongly; a reader who has not met one looks it up. The condition that
brings it back is a tool or a service that Bridge has to be read by.

Refused: the licence's own notice of three paragraphs in every file. It is what its authors
recommend, and nearly six thousand lines that say one thing. The condition that brings it back
is none.

## What the files are called

Of `stage20.md`, *What the files are called*.

Refused: `LICENSE` and `CLA.md` in capitals, excepted from rule O4. It is the custom; and it is
an exception where the method reshapes. The condition that brings it back is the hosting
service not recognising the name in lower case.

## What else is under it

Of `stage20.md`, *What else is under it*.

Refused: the documents under a licence for prose. They hold layouts and code that are the
library's, and where one licence ends is not clear. The condition that brings it back is none.

Refused: the modules of the tests and the SDKs under a permissive licence. It brings back the
question of what seam code compiled into a module is under, and changes nothing for a module
used with Bridge. The condition that brings it back is none.

## Where other terms are asked for

Of `stage20.md`, *Where other terms are asked for*.

Refused: an address in the tree, alone or beside the account. It is what a buyer expects, and
it is harvested from a public file. The condition that brings it back is a buyer who cannot
use the account.

Refused: the line as first ruled, on two lines. It keeps every word, and every header grows by
a line. The condition that brings it back is none.

## When the workflows run

Of `stage20.md`, *What was found on the way*.

Refused: on every push to any branch, as they were written. Nothing had ever run, so what it
costs had never been seen: a stage of twenty pushes would have spent a month's allowance. The
condition that brings it back is minutes that are not counted, which is a public repository.

Refused: only when started by hand. It is a check nobody runs. The condition that brings it
back is none.

## A module, and a backend, as a host

Of `stage20.md`, *A module, and a backend, as a host*.

Refused: a clause added to the licence saying a module and a backend are under it. The licence
lets a recipient ignore a restriction added to it, so it would say nothing in law. The condition
that brings it back is none.

Refused: the statement in `licence.md` only, and nothing in the seam files. Whoever writes a
module reads the header and not that document. The condition that brings it back is none.

## Who the holder is, ruled again

Of `stage20.md`, *Who the holder is*.

Refused, after it had been ruled: "Heuretes-Workshop" kept in the notices. It is an
organisation with other members, and reads as a group holding the rights. The condition that
brings it back is none.

Refused: the author's real name, in every notice or once in `licence.md`. It is the strongest
evidence; and it ties that name to the one on every commit, in public, which cannot be undone.
The condition that brings it back is the author choosing to be named, which is a change of one
script.

Refused: the name the commits are made under, alone or with the account's beside it. It keeps
the author private and matches the history; it was passed over for a role, which also holds
when the rights pass to an entity. The condition that brings it back is none.

Refused: "Bridge Author". The author never changes and the holder may, and a contributor is an
author too. The condition that brings it back is none.

Refused, after one run of it: the platforms run for `main` as for `dev`. It is the same tree
run twice, at about 410 minutes each. The condition that brings it back is a commit that
reaches `main` by another way than `dev`.
