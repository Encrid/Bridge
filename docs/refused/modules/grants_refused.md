## What a module may destroy

Of `grants.md`, *What a module may destroy*.

Refused: a write grant over everything the entity carries. A module that decorates an entity with a
component of its own would then stop every other module destroying it, until the deployment granted
each pair. The condition that brings it back is a component that must never be removed by a module
the deployment did not name for it.

Refused: any entity, which is what this was. The condition that brings it back is grants no longer
being the deployment's statement of who may touch what.
