## Capabilities, so the swap is honest

keeping the guarantee, and gave one thing two words, one where it was asked and one where it was
answered. No condition brings it back.

states that nothing contains a module's code, and a wrong signature is one more thing nothing
contains. The condition that brings it back is a deployment that must have exports checked on a
backend that does not contain its modules.

give one field two readings. `config.md`, *No unaccountable values*. No condition brings it back.
