# What was refused: The log

The record of `log.md`: `README.md`, *Three layers, three seams*.

## The log

Refused: one, which is four bytes a record fewer and sends the second number into text a module
would have to build. The condition that brings it back is records measured as what logging costs.

Refused: three, which is a record of 28 bytes for what text can already carry. The condition that
brings it back is lines that need three, with the building of text measured as a cost.

Refused: a signed scale with warn at -2 and err at -3, which is what this was. Those were flecs'
numbers, taken when its output shared the sink, and nothing was at -1 for no reason anyone here
could give. No condition brings it back.

Refused: the same scale with the hole closed. The condition that brings a scale of our own back is a
need for more than eight levels.

Refused: a `log_level` of zero taken as a severity, which is what this did, and was the one key
that meant something when nobody had stated it. No condition brings it back.

Refused: the key in other numbers than a record's level, shifted by one so that zero is free. Two
scales for one thing. Refused: a second field saying the level was stated, a field whose job is
another field's. The condition that brings either back is "emergencies only" having to be stated,
which 1 does not quite say.
